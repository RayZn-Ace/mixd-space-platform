PRODUKTIDEE
==================================================

MIXD.SPACE ist kein klassisches Coworking Center.

Die Marke soll flexible, hochwertige Arbeitsräume so einfach buchbar machen wie ein modernes Hotelzimmer.

Der gesamte Prozess soll möglichst digital funktionieren:

Space finden
→ Verfügbarkeit prüfen
→ Zeitraum auswählen
→ buchen
→ bezahlen
→ Buchungsbestätigung erhalten
→ digitalen Zugang erhalten
→ arbeiten
